# 《弄染寻踪·火种永续》综合游戏化PRD

**项目名称**：弄染寻踪·火种永续——陆瑞光革命历史研学闯关网页游戏  
**文档版本**：V4.0（综合重构版）  
**文档性质**：产品需求文档（PRD）+ 游戏内容文档 + 技术设计文档  
**编制日期**：2026年8月

## 第一部分：产品需求文档（PRD）

### 一、项目概述

#### 1.1 项目定位

为镇宁县陆瑞光纪念馆打造一款**轻量化网页版红色研学互动游戏**。融合**2D角色冒险（RPG-like）+ Galgame剧情驱动 + 多元化微玩法**，构建沉浸式红色研学体验。无需下载APP，微信扫码即玩。

#### 1.2 核心体验升级

| 维度 | V1.0（原方案） | V3.0（综合方案） |
|------|---------------|------------------|
| 核心玩法 | 知识问答闯关 | 2D角色探索冒险 + Galgame叙事 + 微玩法融合 |
| 交互方式 | 点击按钮答题 | 键盘/触控操控角色移动 + 对话选择 + 操作解谜 |
| 空间体验 | 无空间感 | 2D俯视角可探索地图 + 场景切换 |
| 叙事深度 | 线性文字阅读 | Galgame对话系统 + 分支选择 + 立绘演出 |
| 玩法多样性 | 单一（问答） | 6种以上互动玩法（解谜/节奏/搜索/操作等） |
| 情感代入 | 弱 | 强（角色化身 + 第一人称选择 + 身体操作记忆） |

#### 1.3 技术定位

纯前端H5应用，无需后端服务，所有数据本地存储。但**玩法复杂度对标轻量级RPG游戏**。

### 二、用户与需求分析

#### 2.1 目标用户细化

| 用户群 | 特征 | 核心诉求 | 设计应对 |
|--------|------|----------|----------|
| 中小学生（10-15岁） | 好动、注意力短、喜好操作互动 | 有趣、不枯燥、有成就感 | 微玩法高频打断、即时反馈、收集养成 |
| 高中生/大学生（16-22岁） | 有一定历史基础、追求深度 | 学到知识、有代入感、可分享 | Galgame深度叙事、选择分支、证书体系 |
| 党员/研学团体（22-45岁） | 团队参与、有组织性 | 集体学习、可量化成果 | 战队系统、排行榜、集体成就 |

#### 2.2 用户痛点 vs 解决方案

| 痛点 | 解决方案 |
|------|----------|
| 传统参观枯燥 | 用RPG探索+剧情驱动替代被动参观 |
| 知识记不住 | 用操作体验+身体记忆替代纯文字阅读 |
| 缺乏参与感 | 可操控角色自主探索，而非被动翻页 |
| 缺少社交传播 | 战队系统+成就墙+研学报告卡片分享 |
| 没有深度 | Galgame分支叙事满足不同学习深度需求 |

## 第二部分：游戏内容文档

### 五、完整关卡设计

#### 5.1 序章：寻访启程

**地图场景**：档案馆内部（室内场景）  
**氛围基调**：静谧、探索、庄严

| 环节 | 类型 | 内容 |
|------|------|------|
| 探索 | 地图移动 | 角色在档案馆中行走，靠近档案架触发剧情 |
| 剧情 | Galgame对话 | 馆长出现，介绍陆瑞光基本档案 |
| 微玩法 | 信息整理 | 将散落的档案卡片拖入正确位置（姓名/民族/出生/籍贯） |
| 剧情 | Galgame对话 | 档案拼合完整，获得【手稿残页】物证 |
| 物证 | 山野布衣 | 序章通关徽章 |

**档案卡片玩法详情**：

- 4张卡片：姓名（陆瑞光）、民族（布依族）、出生（1901年）、籍贯（镇宁）
- 4个空位，拖拽匹配
- 全部正确后触发剧情推进

#### 5.2 第一章：乱世奋起

**地图场景**：民国时期镇宁村寨（室外场景）  
**氛围基调**：压抑、抗争

| 环节 | 类型 | 内容 |
|------|------|------|
| 探索 | 地图移动 | 穿过村寨，看到百姓受压迫场景 |
| 剧情 | Galgame对话 | 陆瑞光讲述民国苛捐杂税 |
| 微玩法① | 平衡操作 | "压迫天平"——点击反抗按钮平衡天平 |
| 剧情 | Galgame对话 | 陆瑞光决定召集四十八寨 |
| 微玩法② | 拖动归位 | 将寨名拖到地图正确位置 |
| 剧情 | Galgame对话 | 联盟成立，获得【古铜怀表】物证 |
| 物证 | 乱世英豪 | 第一章通关徽章 |

**压迫天平详情**：

- 画面显示天平，左侧为"官府压迫"，右侧为"百姓承受"
- 初始严重失衡（左侧重）
- 玩家点击"反抗"按钮，左侧逐渐减轻
- 天平平衡时完成，象征抗争的必要性

**四十八寨地图详情**：

- 显示镇宁周边简化地图
- 4-6个寨名浮在画面中
- 玩家拖拽到地图上对应的标记点
- 全部归位后完成

#### 5.3 第二章：弄染相逢（核心篇章）

**地图场景**：弄染寨内外（含寨门、议事厅）  
**氛围基调**：紧张→信任→庄严

| 环节 | 类型 | 内容 |
|------|------|------|
| 探索 | 地图移动 | 走向寨口，远望红军队伍 |
| 剧情 | Galgame对话 | 陆瑞光观察红军，询问你的看法 |
| 微玩法① | 画面搜索 | 从场景图中找出红军与军阀的区别特征 |
| 剧情 | Galgame对话 | 红军抵达寨门，陆瑞光决定迎接 |
| 微玩法② | 节奏共鸣 | 会谈关键时刻，节奏点击象征"同心" |
| 剧情 | Galgame对话 | 彭德怀、杨尚昆与陆瑞光会谈 |
| 微玩法③ | 拼图解谜 | 拼合《反蒋抗日作战协定》碎片 |
| 剧情 | Galgame对话 | 协定签订，历史性一刻 |
| 物证 | 弄染之盟 | 第二章核心徽章 |

**画面搜索详情**：

- 展示一幅山路队伍全景图
- 目标元素：红旗、整齐队列、农民送水、枪口朝下
- 干扰元素：军阀徽记、抢掠物品
- 限时20秒，点击圈出全部目标
- 命中率≥80%通过

**节奏共鸣详情**：

- 屏幕上出现节奏光点，沿轨迹移动
- 光点到达圆心时点击
- 连续命中5次触发"历史性握手"动画
- 难度低，重在仪式感

**协定拼图详情**：

- 4×3切割，共12块
- 拼图背景显示协定文字"联合反蒋抗日"
- 拼完整后浮现陆瑞光与彭德怀签名

#### 5.4 第三章：信守盟约

**地图场景**：弄染寨内（民居、粮仓、山路）  
**氛围基调**：紧迫、信任

| 环节 | 类型 | 内容 |
|------|------|------|
| 探索 | 地图移动 | 寨中穿梭，看到伤员被秘密安置 |
| 剧情 | Galgame对话 | 陆瑞光展示如何安置12名红军伤员 |
| 微玩法 | 快速反应+微策略 | 敌方搜查，点击房屋分配伤员隐蔽 |
| 剧情 | Galgame对话 | 安全躲过搜查，获得物资清单 |
| 物证 | 忠信守盟 | 第三章通关徽章 |

**掩护伤员详情**：

- 展示寨子俯视图，9个可藏匿点（3×3网格）
- 12名伤员需要分配，每个藏匿点可藏1-2人
- 敌人从左侧接近，会搜索路线上的房屋
- 玩家需要在敌人到达前完成分配
- 不可超过房屋容量，不可集中藏匿
- 全部安全后通过

#### 5.5 第四章：烈火忠魂

**地图场景**：贵阳八角岩监狱（室内）  
**氛围基调**：沉痛、肃穆

| 环节 | 类型 | 内容 |
|------|------|------|
| 探索 | 地图移动 | 走入阴冷的监狱走廊 |
| 剧情 | Galgame对话 | 陆瑞光被捕受审，敌军威逼利诱 |
| 微玩法 | 情绪表达（长按） | 按住屏幕体验"坚守"的意志力 |
| 剧情 | Galgame对话 | 宁死不屈，英勇就义 |
| 物证 | 烈火忠魂 | 第四章通关徽章 |

**狱中坚守详情**：

- 画面显示"你可以选择——"
- 长按按钮，进度条逐渐充满
- 需要持续按住10秒（中间可看到进度）
- 进度条满时触发"宁死不屈"剧情动画
- 中途松手则重来（象征坚守不可中断）

#### 5.6 第五章：火种千秋

**地图场景**：陆瑞光纪念馆（现代场景）  
**氛围基调**：庄重、传承

| 环节 | 类型 | 内容 |
|------|------|------|
| 探索 | 地图移动 | 走入纪念馆大厅 |
| 剧情 | Galgame对话 | 馆长介绍纪念馆建设与杨尚昆题词 |
| 微玩法 | 薪火相传（多阶段） | 引火→护火→传火→燎原 |
| 剧情 | Galgame对话 | 全部完成，英雄精神永存 |
| 物证 | 火种千秋 | 终章终极徽章 |

**薪火相传详情**：

- 阶段①引火：快速点击钻木取火（10次）
- 阶段②护火：倾斜设备保持火焰不灭（陀螺仪/鼠标拖拽维持平衡）
- 阶段③传火：将火焰拖向"纪念馆"图标
- 阶段④燎原：点击扩散，火焰覆盖整张地图
- 完成后解锁终章

#### 5.7 终章：时间线拼图+证书

**功能**：

1. 展示全部6件物证（含序章+5章）+ 隐藏物证（如有）
2. 时间线拼图：将以下事件按顺序拖入时间轴
   - 1901年出生 → 1920s成为四十八寨领袖 → 1935.4弄染结盟 → 1935.5收留伤员 → 1937年就义 → 1989年追认烈士
3. 输入姓名 → 生成研学电子证书
4. 显示总积分、通关时间

#### 8.4 各微玩法实现要点

**① 拼图解谜（PuzzleGame）**

- 图片切割为N×M块，打乱顺序
- 检测点击→选中→再次点击交换位置
- 判定全部归位即完成

**② 画面搜索（SearchGame）**

- 在Canvas上绘制场景图
- 目标区域预先定义（矩形坐标）
- 点击检测是否在目标范围内
- 全部找到即完成

**③ 节奏共鸣（RhythmGame）**

- 定义轨迹路径（贝塞尔曲线或直线）
- 关键点位置预定义
- 检测点击时机与关键点距离
- 连续命中达成目标次数即完成

**④ 信息整理（SortGame）**

- 定义拖拽对象和目标槽位
- 实现拖拽逻辑（mousedown/mousemove/mouseup + touch）
- 判定对象是否落入正确槽位
- 全部归位即完成

**⑤ 快速反应（ReactionGame）**

- 敌人/危险物沿路径移动
- 玩家点击分配/躲避操作
- 判定成功/失败条件
- 达成目标即完成

**⑥ 情绪表达（EmotionGame）**

- 长按检测（mousedown/touchstart开始计时，mouseup/touchend停止）
- 进度条随时间增加
- 达到阈值即完成，中途中断则重置

**⑦ 薪火相传（ChainGame）**

- 多阶段状态机管理
- 每个阶段不同操作要求
- 全部完成触发结局

**⑧ 时间线拼图（TimelineGame）**

- 事件卡片可拖拽
- 插槽位置固定（按时间顺序）
- 全部正确归位即完成

### 十一、性能优化策略

| 优化点 | 方案 |
|--------|------|
| 地图渲染 | 离屏Canvas缓存静态图层，仅渲染动态元素 |
| 图片资源 | WebP格式优先，降级JPEG；使用Image.decode()预加载 |
| 微玩法 | 按需加载，非当前玩法不初始化 |
| 动画 | requestAnimationFrame节流，不可见时暂停 |
| 内存管理 | 场景切换时清理定时器、事件监听、离屏Canvas |
| 首屏加载 | 骨架屏 + 渐进式加载（先文字后图片） |
