# 《网页版·陆瑞光纪念馆红色闯关游戏项目开发文档》

**项目名称**：弄染寻踪·火种永续——陆瑞光革命历史研学闯关网页H5  
**文档版本**：V1.0  
**文档性质**：正式项目开发文档

---

## 一、项目概述

### 1.1 项目名称

**弄染寻踪·火种永续——陆瑞光革命历史研学闯关网页H5**

### 1.2 项目定位

为镇宁县陆瑞光纪念馆打造一款轻量化网页版红色研学互动游戏。无需下载APP，微信扫码、浏览器直接打开，面向青少年、大学生、党员、研学游客。风格庄重、纪实、年轻化，去除低幼卡通风格，主打沉浸式历史剧情+知识性闯关+实地展厅联动。

### 1.3 建设目标

1. 以陆瑞光生平时间线串联纪念馆全部展陈知识点
2. 实现线上云研学、线下展厅扫码解锁双模式
3. 通过剧情闯关提升游客对“弄染结盟”红色历史的理解
4. 输出电子徽章、研学证书，提高传播与留存
5. 打造纪念馆数字化文旅、智慧研学亮点项目

### 1.4 运行环境

- **载体**：移动端H5网页（自适应电脑端）
- **运行环境**：微信内置浏览器、手机浏览器、电脑浏览器
- **用户系统**：无需安装、无需注册（可选匿名游玩）

## 二、用户与需求分析

### 2.1 目标用户群体

- 中小学研学学生、高校大学生
- 党政机关、企事业单位党员研学群体
- 纪念馆参观游客、红色文化学习者

### 2.2 用户痛点

1. 传统参观枯燥、记不住历史知识点
2. 讲解内容冗长，游客吸收度低
3. 缺少可互动、可留存、可传播的数字化研学成果
4. 无线上前置学习渠道

### 2.3 项目解决能力

1. **剧情化闯关**：把展厅知识点变成故事
2. **答题带史料解析**：答错也能学知识
3. **线上预习、线下深化结合**
4. **徽章+证书体系**，形成研学闭环

---

## 三、整体产品架构

### 3.1 产品模式

**时间线剧情闯关 + 知识问答 + 识图解谜 + 线下展厅扫码联动**

### 3.2 整体章节结构（对应纪念馆展厅分区）

| 章节 | 主题 | 对应展区 |
| :--- | :--- | :--- |
| 序章 | 寻访启程 | 开篇导入 |
| 第一章 | 乱世奋起 | 早年抗争展区 |
| 第二章 | 弄染相逢 | 弄染结盟核心展区 |
| 第三章 | 信守盟约 | 支援红军展区 |
| 第四章 | 烈火忠魂 | 英雄就义展区 |
| 终章 | 火种千秋 | 精神传承、证书解锁 |

### 3.3 核心功能模块

1. 剧情动画页（文字叙事+背景图）
2. 多题型答题系统
3. 线下展厅二维码解锁隐藏线索
4. 徽章收集系统
5. 研学电子证书生成系统
6. 错题史料解析库
7. 本地缓存进度（再次打开不重玩）

## 四、页面详细设计（前端开发直接对照制作）

### 页面1：首页启动页

- **视觉**：红色纪实简约风、老照片底纹、庄重书法标题
- **内容模块**：
  - 主标题：弄染寻踪 · 火种永续
  - 副标题：陆瑞光革命历史线上研学闯关
  - 按钮1：开始寻访
  - 按钮2：游玩说明

**游玩说明固定文案**：

1. 本闯关以陆瑞光革命生平时间线完整还原纪念馆红色历史
2. 共5大篇章，循序渐进学习布依英雄革命事迹
3. 部分隐藏线索可在馆内扫码解锁
4. 答错题目自动弹出史料解析，边玩边学
5. 通关可集齐徽章、生成官方研学证书

---

### 页面2：序章剧情页

- **剧情导入文案**：
    > 百年星火，照鉴初心。布依族英雄陆瑞光，生于乱世、挺身为民、结盟红军、信守忠义、以身殉国。你将以历史寻访者身份，一步步解锁镇宁弄染红色记忆。
- **题型**：基础入门题
- **通关奖励**：徽章《山野布衣》

---

### 页面3~12：五大篇章闯关主页面

每章统一结构：

1. 篇章剧情介绍
2. 3~5道知识闯关题
3. 答对进入下一段剧情
4. 答错弹出【史料解析】可重答
5. 通关解锁对应专属徽章

---

### 页面13：终章汇总页

- **展示**：全部5枚徽章合集、通关寄语
- **功能**：输入姓名 → 一键生成【电子研学证书】
- **证书操作**：可截图、可转发、可保存。

## 五、五大关卡完整内容设计（对标展厅）

### 第一章：乱世奋起｜早年抗争展区

- **主题**：布衣奋起，救民于乱世
- **知识点覆盖**：
  - 陆瑞光出生年份、籍贯、民族
  - 民国地方局势、民众受压迫背景
  - 四十八寨头领、四大天王称号
- **题型**：单选、人物匹配

### 第二章：弄染相逢｜核心结盟展区（重点章节）

- **主题**：军民同心，弄染结盟
- **知识点覆盖**：
  - 1935年红军过境镇宁
  - 彭德怀、杨尚昆与陆瑞光会谈
  - 弄染反蒋抗日作战协定
  - 弄染结盟历史地位
- **题型**：时间排序、史料识图、情景思辨题

### 第三章：信守盟约｜支援红军展区

- **主题**：一诺千金、守护红军
- **知识点覆盖**：
  - 收留12名红军伤病员
  - 提供物资、向导、掩护
  - 布依族群众拥军故事
- **题型**：填空、多选、场景拼图

### 第四章：烈火忠魂｜英雄就义展区

- **主题**：宁死不屈、忠义千秋
- **知识点覆盖**：
  - 1937年贵阳八角岩牺牲
  - 被捕原因、坚贞不屈事迹
  - 1989年追认为革命烈士
- **题型**：单选、简答感悟题

### 第五章：火种千秋｜精神传承尾厅

- **主题**：英雄不朽、薪火相传
- **知识点覆盖**：
  - 杨尚昆题写馆名
  - 纪念馆建设历程
  - 爱国主义教育基地价值
- **题型**：综合复盘题

## 六、题库体系规范（开发标准）

### 6.1 题型分类

1. 单选题（基础）
2. 多选题（进阶）
3. 填空题（重点记忆）
4. 时间排序题（历史逻辑）
5. 史料识图题（展厅文物联动）
6. 情景思辨题（青年研学拔高）

### 6.2 错题机制

- 所有题目答错 **不扣分、不重置进度**
- 自动弹出：标准史料解析
- 支持无限次重做

### 6.3 题库特点

全部题目100%对标陆瑞光纪念馆官方史实，无杜撰、无低幼化内容。

## 九、UI视觉规范（硬性要求）

1. **主色调**：中国红 + 暗金 + 素白
2. **风格**：纪实、简约、庄重、年轻化
3. **禁止元素**：卡通、Q版、幼稚风格
4. **背景元素**：老照片肌理、宣纸纹理、暗纹党史元素
5. **字体**：标题使用书法体，正文使用清晰黑体

## 十、技术开发方案（前端可直接用）

### 10.1 技术栈

**H5 + CSS3 + JavaScript** 轻量化开发、无需后端复杂接口

### 10.2 核心技术功能

1. 本地LocalStorage缓存闯关进度、徽章状态
2. 自适应响应式（手机/电脑全部适配）
3. 图片轻量化压缩、秒开不卡顿
4. 二维码扫码识别、携带参数解锁隐藏题库
5. 证书图片合成、一键保存
6. 答题对错逻辑+解析弹窗系统

### 10.3 部署方式

1. 可独立域名部署
2. 可嵌入纪念馆官方官网
3. 可挂在公众号菜单
