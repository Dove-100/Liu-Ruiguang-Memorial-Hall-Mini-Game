# 《弄染寻踪·火种永续》角色移动+关卡交互升级方案

**文档性质**：基于原项目文档的玩法架构升级方案  
**核心目标**：引入可操控移动角色，以Galgame式剧情驱动模式重构关卡体验，打造「自由探索 + 深度叙事 + 知识闯关」融合玩法

## 一、核心玩法架构重塑

### 1.1 整体设计理念

| 维度 | 原方案 | 升级方案 |
|------|--------|----------|
| 交互方式 | 点击按钮翻页答题 | 操控角色在地图中移动探索 |
| 关卡入口 | 线性章节列表 | 角色走到对应位置触发剧情 |
| 叙事模式 | 文字剧情+答题 | Galgame式对话+选择分支 |
| 空间感 | 无（纯页面堆叠） | 有（2D俯视角场景地图） |
| 沉浸层级 | 旁观者 | 角色化身+情感代入 |

### 1.2 核心玩法循环

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   ┌──────────┐     ┌──────────┐     ┌──────────┐              │
│   │ 自由探索  │ ──→ │ 触发剧情  │ ──→ │ 剧情对话  │              │
│   │ (地图移动)│     │ (到达点位)│     │ (Galgame) │              │
│   └──────────┘     └──────────┘     └──────────┘              │
│         ↑                                ↓                      │
│   ┌──────────┐     ┌──────────┐     ┌──────────┐              │
│   │ 返回探索  │ ←── │ 获得反馈  │ ←── │ 互动选择  │              │
│   │ (继续寻访)│     │ (知识+物品)│     │ (分支推进)│              │
│   └──────────┘     └──────────┘     └──────────┘              │
│                                                                 │
│   每章循环一次，每次触发不同剧情节点，推进主线                   │
└─────────────────────────────────────────────────────────────────┘
```

### 2.2 地图移动机制

| 设计要素 | 具体说明 |
|----------|----------|
| 操作方式 | 移动端：虚拟摇杆或点击地面移动；桌面端：键盘方向键/鼠标点击 |
| 移动反馈 | 角色行走动画（像素风格）+ 脚印粒子效果（轻微） |
| 碰撞检测 | 地图边界碰撞 + 不可通行区域（山体、河流） |
| 视野控制 | 角色居中，地图随角色移动滚动 |

### 2.3 角色设计

**角色形象**：以年轻化“红色研学记者”为原型，穿着简朴民国风服饰，辨识度高。

```
角色状态设计：
┌─────────────────────────────────────────────┐
│  🚶 行走状态  →  普通移动                   │
│  🧐 调查状态  →  靠近可交互对象时           │
│  💬 对话状态  →  触发剧情时（Galgame模式）  │
│  ⭐ 通关状态  →  完成章节后（带有光效）     │
└─────────────────────────────────────────────┘
```

### 2.4 地图交互元素

散布在地图中的各类可交互对象，玩家靠近后触发互动：

| 交互类型 | 视觉标识 | 交互反馈 | 示例 |
|----------|----------|----------|------|
| 剧情触发点 | 金色光圈脉动 | 进入Galgame对话模式 | 章节入口 |
| 知识碎片 | 书籍图标漂浮 | 弹出史料卡片 | 背景知识补充 |
| 隐藏线索 | 微弱闪光 | 获得物证/解锁彩蛋 | 馆内扫码联动 |
| NPC角色 | 人物头像标识 | 触发对话/选择分支 | 历史人物再现 |
| 传送点 | 箭头光效 | 跨场景移动 | 章节间过渡 |

## 三、核心机制二：Galgame式剧情驱动模式

### 3.1 Galgame模式UI框架

当玩家走到剧情触发点时，游戏进入Galgame模式，画面切换为：

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   [背景：1935年弄染寨实景风格插画，带老照片滤镜]              │
│                                                                 │
│                    ┌─────────────────────┐                      │
│                    │  人物立绘（左）     │  ← 对话者形象       │
│                    │  （陆瑞光/彭德怀   │                      │
│                    │   等历史人物）      │                      │
│                    └─────────────────────┘                      │
│                                                                 │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │  💬 对话文本框                                           │   │
│   │  “你终于来了。我是陆瑞光，弄染寨的布依族头领。          │   │
│   │    听说你是从外面来的研学记者？”                        │   │
│   │                                                          │   │
│   │  ┌──────────────────────────────────────────────────┐    │   │
│   │  │  ▶ 点击继续                              [自动] │    │   │
│   │  └──────────────────────────────────────────────────┘    │   │
│   └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│   [底部：角色名]  [右上角：跳过/历史记录/设置]                  │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 对话系统核心功能

| 功能 | 说明 |
|------|------|
| 逐句显示 | 文字逐字显现，模拟真实对话节奏（可跳过） |
| 自动模式 | 开启后对话自动推进，适合沉浸观看 |
| 历史记录 | 可回看已出现的对话文本 |
| 立绘切换 | 不同角色切换时伴随淡入淡出效果 |
| 背景变化 | 剧情推进时背景可随场景变化 |

### 3.3 Galgame模式中的选择分支

在对话关键节点弹出 **选择肢**，玩家选择影响剧情走向和获得内容：

```
┌─────────────────────────────────────────────────────────────────┐
│   💬 陆瑞光：“红军纪律严明，不扰百姓，与我们见过的军队     │
│      都不一样。你说，我该不该信他们？”                       │
│                                                                 │
│   ┌─────────────────────────────────────────────────────────┐   │
│   │  📖 “我曾在书中读过红军的故事，他们是为穷人打仗的”   │   │
│   │  🤝 “眼见为实，我愿陪你一起下山见见他们”             │   │
│   │  ⚖️ “谨慎些好，先派人观察几日再做决定”               │   │
│   └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│   💡 提示：不同选择将导向不同的剧情展开，但历史结局不变       │
└─────────────────────────────────────────────────────────────────┘
```

### 3.4 与知识问答的融合方式

**核心思路：知识问答不再以“考试”形式出现，而是自然融入对话选择中。**

| 原方式 | Galgame融合方式 |
|--------|-----------------|
| 单选题：陆瑞光哪年出生？ | 对话中自然提及：“你生于哪一年？”“我生于1901年……” |
| 匹配题：四大天王之首？ | 对话中其他角色称呼：“四大天王之首，久仰大名” |
| 填空题：收留12名伤员 | 剧情动画展示：伤员被抬进屋，旁白“一共12人……” |
| 时间排序题 | 对话中回忆：“那年4月，红军先到了寨子……” |

**当需要玩家主动回忆/应用知识时**，以选择肢形式呈现：

> 💬 彭德怀：“我们想与陆首领签订一份反蒋作战协定，你对此怎么看？”
>
> ┌─────────────────────────────────────────────────┐
> │  📜 “反蒋作战？具体是指什么？”                 │
> │  🤝 “只要有利于百姓，我全力支持！”             │
> │  ❓ “请讲清楚协定内容，我们再议”               │
> └─────────────────────────────────────────────────┘
>
> 选择正确选项后：获得【历史洞察】成就 + 推进剧情
> 选择其他选项：角色会补充解释，引导玩家理解后再选择

## 六、UI/UX与视觉规范补充

### 6.1 地图视觉风格

- **俯瞰视角**：2D正投影，非等距
- **绘制风格**：写实插画风，带做旧纹理，符合“纪实”定位
- **配色方案**：以墨绿、土黄、暗红为主，避免高饱和色彩
- **图层顺序**：地面→植被→建筑→角色→UI（由下至上）

### 6.2 Galgame模式视觉规范

| UI元素 | 规范 |
|--------|------|
| 对话框 | 半透明深色底，下置，占画面25%高度 |
| 文字 | 白色/浅金色，大字号，字间距舒适 |
| 立绘 | 半身像，位置左/右，带阴影，风格为纪实素描 |
| 背景 | 全景插画，带老照片颗粒滤镜 |
| 选择肢 | 卡片式按钮，悬停/选中时金色描边 |
| 跳过按钮 | 右上角，小字号，不影响沉浸 |

### 6.3 移动端适配要点

- 虚拟摇杆位于屏幕左下角，半透明，不遮挡地图
- 对话区域在移动端占比增大（便于点击）
- 选择肢按钮高度不小于44pt（手指友好）

## 八、与原方案对照总结

| 维度 | 原方案 | Galgame+地图探索方案 |
|------|--------|---------------------|
| 核心交互 | 点击按钮→答题 | 操控角色移动→触发剧情→对话选择 |
| 空间感知 | 无 | 强（地图探索带来沉浸感） |
| 叙事深度 | 文字阅读 | 角色对话+立绘+选择代入 |
| 知识传递 | 问答考试式 | 自然融入剧情对话与选择 |
| 重复可玩性 | 低 | 中（不同选择解锁不同对话内容） |
| 技术复杂度 | 低 | 中等 |
| 开发工时 | 8天 | 15.5天 |
| 教育效果 | 知识记忆 | 知识理解+情感认同 |
