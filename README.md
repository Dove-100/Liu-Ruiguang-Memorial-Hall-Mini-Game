# 《弄染之约》数字研学对话游戏

这是依据《陆瑞光生平史实与游戏剧情对应稿》重新制作的全屏对话剧情游戏。旧版网页代码与测试已删除；新版本以展开后的三章对话为主线。

## 体验方式

直接打开 `dist/index.html`，或在 `dist` 目录启动任意静态文件服务器。

## 操作

- 点击对白框、按空格或回车：继续对话；正在逐字显示时会先完整显示本句。
- 点击右侧选项：作出调查判断；错误选项不会扣分，会获得史料提示。
- “册”：打开走访手册，查看已获线索、时间线和资料来源。
- “自”：开启或关闭自动播放。
- “返”：返回标题画面；进度会自动保存在当前浏览器。

## 内容原则

- 石伯、兰婆、周伯为虚构的当代讲述者。
- 陆瑞光及红军领导人不使用虚构对白、心理独白或遗言。
- 史料数字存在异文时，主线采用能够稳定确认的概括，并在剧情中解释差异。
- 场景背景为原创游戏绘景，不是历史照片；地图和路线为叙事示意。
